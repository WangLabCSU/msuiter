# The FFI export surface (ffi-surface) review artifact

> Status basis: `docs/ARCHITECTURE.md` §2 (the FFI hard contracts 1–8), §3.5 (`docs/ffi-surface.md` is the per-release review artifact); established at U-M0-09.
> Scope: every `#[extendr]` export of the root crate (the FFI shell) (`msffi_*`, registered into the `msuiter` dynamic library through the `wrap__*` of `R/extendr-wrappers.R`). The engine/catalog crates have no FFI surface and are not in this table.
> **This file is a frozen artifact**: the repository guard test (`tests/testthat/test-ffi-surface-drift.R`) parses the machine-readable manifest in §"the export manifest" and compares it item by item against the actual export set of the rextendr-generated wrappers; any drift (an addition/a removal/a renaming) turns the test red.
> **Version-stamp semantics (frozen-at-M0, F-14 clarification, corpus pass 2026-10-13)**: every row of the detail table carries the single package-version stamp `0.0.0.9000` because the whole table was sealed as the frozen M0 baseline artifact (U-M0-09); the stamp therefore records the artifact's freezing generation, **not** the per-export introduction version. The actual introduction of each later kernel export is recorded by the unit-ID reference inside its own row (U-M1s-09, U-M2-03, U-M3a-02, U-M3b-03, U-M4-01, U-M7-pre, ...) and by the corresponding devlog entries. The stamped rows are never rewritten (see the convention below and frozen-protocol rule 2).

* The **status** has only two tiers: `diagnostic` (this unit's contract probes / meta-information, no domain algorithm) and `kernel` (a real algorithm-kernel export, entering from M1s). * The error protocol: every `msffi_*`'s `Err(MsError)` is uniformly converted at the ffi boundary to a condition object of class `c("msuiter_error_rust", "error", "condition")` (the payload `message`, `topic`, `i`, `j`, `c`), re-raised by the R wrapper via `stop()`; the abort classes of the R-side validators are `msuiter_error_input` / `msuiter_error_na` / `msuiter_error_option` (the `msuiter_error_<topic>` convention of ARCHITECTURE §3.5).
  **The helper unification completed (2026-09-28, the U-M1s wrap-up small cleanup unit)**: every R-side abort (the six spots of `.ms_tally_rust`, `.ms_validate_matrix/_count/_switch`, `.ms_resolve_threads` and the three spots of `.ms_extract_rust`) is now uniformly emitted through the shared `msuiter_abort()` (R/classes-utils.R), the earlier temporary `rlang::abort(context=)` shape no longer exists. * The statelessness (contract 1) applies to every export: no handle registry table, no `.state`, no silent recomputation; the per-call thread pool is built and destroyed with the call.
