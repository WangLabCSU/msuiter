## 4. 冒烟演练实录（本批执行，产物全在 /tmp/release-smoke/，未入仓库）

1. **`R CMD build`**（含树上未提交的 GMM stratify 工作区状态）：tarball 2,604,302 B，build 干净（logs：空目录 `logs/` 被自动剔除）。
2. **vendor 生成**：`sh tools/vendor.sh` → /tmp/msuiter-vendor.tar.xz（1,863,340 B）→ 复制到 `src/rust/vendor.tar.xz`（gitignore 已覆盖，装后已删除，工作树还原）。**`--check` 报 DRIFT（见 §8 P1-1）**。
3. **CRAN 模式安装**（干净库 `/tmp/release-smoke-lib`，从 tarball 装）：`env -u NOT_CRAN -u DEBUG R CMD INSTALL msuiter_0.0.0.9000.tar.gz -l /tmp/release-smoke-lib` → **exit 0，27.9 s 墙钟**（cargo release 库 13.3 s）。日志证据链齐：`Building for CRAN` → `=== Using offline vendor tarball ===` → `cargo build -j 2 --offline --lib --release` → `--print=native-static-libs` → `rust_clean` 清理 `.cargo`/`vendor`/`target` → `DONE (msuiter)`。**零 warning**。
4. **依赖解析**：`R CMD INSTALL` 不装 Imports——干净库缺 S7/rlang 首跑 `library()` 失败；补装 **S7 0.2.2 / rlang 1.3.0** 后通过。r-universe/CRAN 用户由自动依赖解析覆盖，无风险；但 Release 验证脚本须先 `install.packages(c("S7","rlang"))`。
5. **端到端冒烟**（`/tmp/release-smoke/smoke.R`，脚本内自造最小数据、不依赖 tests/）：内联小端 2bit writer 写合成基因组（chr1 ACAC… 64 bp 含 N 块、chr2 GCGC… 40 bp）→ 41 条双样本 SNV（SA: C>A 为主 / SB: C>G 为主）→ `ms_variants()` → `ms_tally(mode="SBS96")`（96×2，n_skipped=0）→ `ms_extract(k=2)` → **MsSignature 七字段齐**（signatures 96×2 colSums=1、exposures 2×2、catalog_summary n_channels/n_samples/channel_name/channel_hash/build、engine="nmf"、seed=1、stability、k_evidence）；**重构误差 = 0**（signatures %*% exposures vs counts）；**重复拟合 identical = TRUE**（确定性锚）。**SMOKE PASS**。
