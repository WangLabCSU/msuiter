## §1 ms_downsample() 冻结设计

```r
ms_downsample(catalog, depth = "min", seed = 1)
```
- `catalog`：MsCatalog（channels × samples 计数）。
- `depth`：正整数（公共目标深度）或 `"min"`（活样本最小总量）。
- 语义（冻结）：逐活样本 `total_j > depth` ⇒ `counts*_j ~ Multinomial(depth, counts_j / total_j)`；`total_j ≤ depth` ⇒ 原样保留（不下采样不上采样）；`total_j = 0` ⇒ 死样本保持零列。下采样只减不补——诚实退化语义与 sanity harness 一致。
- 确定性：单一 `set.seed(seed)` 后按样本列序顺序 `rmultinom`——对给定 catalog + seed 逐位可复现（与 sanity harness 的顺序化 RM 约定一致；非 Rust 流——无 FFI 面，纯 R 数据操作，D13 口径：这是数据准备操作而非推断声明）。
- 返回：新 MsCatalog，channels/labels/samples 原样；provenance 追加 `downsample` 记录（depth/seed/调用时间戳禁入——可复现性优先）。
- 多项近似的诚实声明：有放回多项近似"无放回抽子集"（多元超几何）——深覆盖下偏差可忽略；超几何实现记升级臂（memo 一致模式）。

## §2 COSMIC txt 互操作冻结设计

布局（锚 = 捆绑上游文件逐字节）：TSV，首列头 `Type`，行 = 通道标签（规范序），其后每列一个签名/样本；值 = 概率（签名文件）或整数计数（目录）。

- `ms_export(x, format = "cosmic", file = NULL)`：x ∈ {MsCatalog（counts 列）, MsSignature（signatures 列）}；**标签契约**：行标签必须与通道注册表规范序逐一相等（不允许静默重排/子集——互操作的第一守则），失配 → 结构化 input 错误（首个失配 1-based 行号）。`file = NULL` 返回装配好的 data.frame（管道用）；给了 file → 写出（`write.table` sep="\t" quote=FALSE）并 invisible 返回路径。浮点格式不声称逐字节复现上游（R 浮点格式化差异；布局/标签/数值逐位声称）。
- `ms_import(file, format = "cosmic", kind = c("catalog", "signatures"), channel_table = NULL)`：读 TSV；首列头必须为 `Type`；行标签匹配注册表——`channel_table` 缺省时按行数+标签集在注册表（SBS96/DBS78/ID83/SBS192/SBS1536）中唯一推断，推断失败 → 错误列举候选。`kind="catalog"` → MsCatalog（整数化校验：非整数值 → input 错误）；`kind="signatures"` → MsSignature（provenance 摘要记 file+hash）。
- 测试：合成目录 export→import 逐位往返（整数计数）；真实 COSMIC v3.6 SBS96 文件 import → 标签集 == 注册表规范序（上游字节锚）+ 值逐位等于 `read.delim`；导出该签名集 → 重读逐位一致。
