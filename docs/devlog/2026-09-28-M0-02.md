# Devlog · U-M0-02 M0 spike（2026-09-28）

## 结果（全部实测数字）
1. **vendor 体积**：22 crates / 970 文件——未压缩 10,674,351 B、tar 13,832,192 B、**xz 1,125,136 B ≈ 1.07 MiB**（xz 版本敏感 ±0.1%，漂移门设容差；未压缩/tar 两口径逐字节可复现）≫ 低于 CRAN 5 MB 指导线 → **依赖预算不触发收缩**（ADR 0002）。
2. **offline / CRAN 模式**：`CARGO_NET_OFFLINE=true` vendor 构建绿；Makevars vendor.tar.xz 接线 R CMD INSTALL（`-j 2 --offline --release` + rust_clean）stable 与 1.71 双工具链全通，安装后 `library(msuiter)` 加载 OK。产物不入库，发布期 `tools/vendor.sh` 再生成（ADR 0002 §3.3）。
3. **MSRV 1.71 证明**：基线失败——matrixmultiply 0.3.11 声明 rust-version 1.75.0（确切错误已录 ADR 0002 §4.1）→ lock 钉版 0.3.9（**不放宽 MSRV**）→ 1.71 冷构建 + CRAN 模式全绿。维护约束：Cargo.lock 保持 v3（v4 需 cargo ≥1.78）；钉版保护进 CI。
4. **twobit 两案裁决**：crate 0.2.2（MIT、零运行时依赖、内建大端反 magic 检测、`TwoBitFile::from_buf(&mmap)` 即 `Cursor<Mmap>` 形态）vs 自研 244 行原型——7 条测试：{LE,BE}×{crate,自研}×独立真值逐位 + 双 reader 互检 + 真实 mmap + 坏 magic 拒绝，stable 1.97.1 与 1.71.0 双跑全绿 → **裁决选 crate**（ADR 0001；synthesis §4 末条"默认倾向 crate"被证据确认）。实验 crate 入库 `tools/spike/twobit-spike/`（独立 `[workspace]` 隔离、无嵌套 .git、`.Rbuildignore` 排除出 R tarball）。
5. **依赖预算变化**：twobit 0.2.2 入 workspace + catalog manifest（**D7 预留位经 ADR 解锁**，其余预算不动）。

## 关键决策（契约引用）
- D7 两案裁决落地；MSRV 1.71 成立（D4/§2，代价 = 一条 lock 钉版）；byte-swap/大端验证口径 = 同一逻辑内容的 LE/BE 双布局文件被逐位一致解析（大端主机正确性的可检验代理，BE 夹具为真实字节翻转文件而非开关）。
