# Data and Code Availability

**All analysis in the accompanying manuscript is fully reproducible from
synthetic data.** No real-data cohort is used anywhere in the benchmark,
calibration, or scenario evidence; the master seed for the synthetic
regime is 20260928 (frozen G0 simulator), and every timing row in the
committed campaigns attests its host and hardware profile.

## Code

- **Package source**: this repository
  ([WangLabCSU/msuiter](https://github.com/WangLabCSU/msuiter)). The vendored
  Rust compute core lives under `src/rust/` and is compiled during
  `R CMD INSTALL` (toolchain floor `rustc >= 1.71`).
- **One-command reproduction**: `MSUITER_REPRO_LIB=<stage-dir> bash
  inst/repro/reproduce.sh --verify` re-derives every sealed number quoted
  in the paper from committed bytes (see
  `vignettes/articles/reproduction-proof.qmd` for the face-by-face
  attestation). `--full` prints the operator recipes (container builds,
  renv restore, campaign regenerations) without executing them.
- **Environment freeze**: `inst/repro/renv.lock` (R 4.5.2 stamp, 111
  pinned packages); container freezes via
  `bench/m7/adapters/Dockerfile.sigprofiler`, `Dockerfile.sigminer`,
  `Dockerfile.nmf_yardstick`; the package itself ships a container recipe
  at `inst/repro/Dockerfile.msuiter`.
- **Benchmark harness**: `bench/m7/` (adapter-docker harness, floor-table
  governance tests, parity recomputer `bench/m7/tools/parity_recompute.py`).

## Data

- **No external datasets are required to reproduce any figure or table.**
  All benchmark inputs are generated by the frozen G0 simulator
  (`bench/g0/`) from committed seeds; per-campaign seed banks are
  committed as `Seeds.txt` under each
  `bench/results/<campaign>/` directory.
- The bundled reference database (`ms_refdb_bundled()`, COSMIC v3.6) is
  licensed data distributed through the governed mirror path
  (`vignettes/articles/architecture.qmd` §6.2); its numerics are never
  committed to this repository.

## Campaign artifacts

Committed campaign artifacts (benchmarks, calibrations, parity censuses,
judgments) live under `bench/results/`; `bench/results/README.md` is the
authoritative index of all 16 campaign directories and the supersession
chain between them.

## Seeded provenance

Every committed witness, census line, and judgment quotes its epoch pin
(current floor-table epoch: `b1ce0f176cec2633`, pinned at
`bench/m7/tests/test_p6_floor_governance.py:169`) and its generating
command, so each figure can be re-derived byte-identically from the
repository alone.
